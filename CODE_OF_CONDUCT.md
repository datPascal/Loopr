# Code of conduct

Treat contributors and users with patience and respect. Technical disagreement is welcome. Harassment, threats, discrimination, sexualized attention, deliberate exposure of private information, and sustained personal attacks are not.

Keep criticism about the work. Assume mistakes are possible, ask for evidence, and make room for people to correct them.

Maintainers may edit or remove comments, issues, pull requests, or contributions that violate these rules. Repeated or serious violations can result in a temporary or permanent ban from the project.

Use GitHub's private reporting controls for platform abuse. If maintainer action is needed, contact the repository owner through the GitHub profile. Do not use a public issue if the report would identify a target or repeat abusive content.
